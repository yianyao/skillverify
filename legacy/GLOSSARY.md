# GLOSSARY — 代号与术语总表（新读者从这里开始）

> 本仓库（specSkill）及 `D:\sData\standardSkill\` 规范体系内的代号，均可在本表查到一句话解释。
> 维护纪律：新增代号先入本表再使用；代号详情（完整条款文本）以 standardSkill 规范文档为准，本表只做"读懂"级别的钥匙。

## 一、生命周期阶段（一个技能从想法到退役的六个阶段）

| 代号 | 全称 | 一句话解释 |
|---|---|---|
| **D** | 设计期 | 立项、取材、边界裁决——写 SKILL.md 之前 |
| **W** | 编写期（内容门 B） | 撰写正文/材料，W 组提示词做语义评审 |
| **E** | 测试期 | 评测集、断言纪律、双评实测 |
| **M0** | 挂载期 | 技能装进宿主后的冒烟确认（可见性/共存/防注入） |
| **M1** | 验收期 | 全门审计与放行（M1 通过=可交付） |
| **R** | 运行期 | 交付后的常态回顾与膨胀预警 |

D/W/E/R 合称即 description 里常出现的"生命周期阶段"。

## 二、手段标注（一项检查"由谁做"）

| 标注 | 含义 |
|---|---|
| **〔纯 H〕** | 只能人工（价值裁决/流程纪律），H=Human |
| **〔L 已实现〕** | LLM 语义评审已覆盖（llm-review 的 29 条提示词），人工仅终审 |
| **〔S 已实现〕** | 脚本可判定且 `tools/` 已有实现，S=Script |
| **〔K/O 已实现〕** | 动态实测已覆盖，K=在环实测（trigger-eval/quality-ab），O=挂载/运行观察 |

例："B2-2 〔L 已实现〕W-04 ⚑ + 〔纯 H〕确认" = 该条先由 W-04 号提示词双评（⚑=双评标记），人工只做确认。

## 三、检查项编号（前缀=来源，数字=规范条款号）

| 前缀 | 来源 | 示例 |
|---|---|---|
| **V** | 规范条款号（standardSkill 规范条目总表），由对应工具机械化 | V2 命名、V8 安全、V11 token、V12 留痕、V18 精简、V21/28/29 评测纪律、V23 防注入 |
| **A** | 格式门（check_skill.py） | A1 官方校验器、A6 行数 |
| **L-xx** | 编写期静态补检（w_static_lint.py 本地编号，验证补全工程甲档工具一） | L-2 无关文件、L-7 引用链二层、L-10 全包宿主路径、L-12 全包 LF/BOM |
| **Q-xx** | 评测期产物校验（eval_artifacts_check.py 本地编号，甲档工具二） | Q-1 查询集 schema、Q-2 切分与冻结、Q-4 grading 对账、Q-7 离群值 |
| **LL-xx** | 乙档 LLM 列表（语义终判，不建脚本，W 组评审承担——验证补全工程裁决） | LL-2 笼统指引终判、LL-6 恶意初筛复核、LL-7 双评一致性 |
| **DEP** | 依赖检测（dep_check.py 本地编号） | DEP-1~5 |
| **EX** | 交付存在性/schema（deliver_check.py 本地编号） | EX-1 验收报告、EX-3 grading schema、EX-6 修订闭环 |
| **W-xx / E-xx / R-xx / D-xx** | llm-review 的提示词编号（前缀=适用阶段） | W-04 精简双评、W-08 防护、E-04 双评、R-02 回顾 |
| **B1~B6 / D1~D5 / E1~E5 / M0 / M1 / R** | 人工评审检查清单的条目分区（= 阶段×主题） | B3-1 约束防护、E4-1 迭代裁决 |
| **B2-1~3** | 编写期"范围与结构"三条（纯 H 终审） | 下次技能修订轮时人工走 |

**门**：门 A=格式、门 C=触发实测（trigger-eval）、门 D=质量对照（quality-ab）、门 M=验收审计。
**V12 留痕** = 规范条款 V12：评审过程与判定须落盘留痕（即 `.verification/` 下各产物）。
**"版本 A/B 对比"** = 盲评（blind review）：新旧两版材料隐去版本标识交评委盲选，llm-review `plan_dual_review.py --blind` 实现。

## 四、结果状态码（所有工具与报告通用）

| 码 | 含义 | 退出码 |
|---|---|---|
| **PASS** | 检查通过 | 0 |
| **INFO** | 仅信息，无合规含义 | 0 |
| **SKIP** | 不适用/条件缺失（不计警告，须人工留痕佐证） | 0 |
| **WARN** | 存疑但非违规，须人工甄别或书面评估 | 2 |
| **FAIL** | 违规阻断 | 1（exit 1=参数/硬错误，exit 2=有 WARN） |
