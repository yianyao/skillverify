## 二、切分与冻结（C3 前置）

- **切分**：12 训练（P01–P05、P10、N01–N05、N08）/ 8 验证（P06–P09、N06/N07/N09/N10），手工指定后**冻结**，禁随机重切（保证跨迭代可比）。
- **隔离纪律（§6.4.3）**：修订 description 只允许依据 train 失败；**validation 结果不得参与任何修改决策**。
- **禁止关键词照抄（§6.4.5）**：若 N 组某条误触发，修订时必须归纳类别/概念覆盖，不得把该查询的具体词直接塞进 description。

## 三、执行协议（C2）

1. **运行方式**：每条查询派发 1 个全新子代理（独立会话，路径 B）。提示词含诚实回报纪律：
   - ① 技能清单中是否可见 agent-skill-llm-review；
   - ② 是否经 Skill 工具加载该技能（**以子代理工具调用历史为证**，§6.3.2 判定标准）；
   - ③ 最终回答原文。
   - 禁止子代理读技能目录"找答案"。
2. **频次**：每条 ≥3 次（§6.3.1），全量 60 次运行；支持结果明确后提前终止（§6.3.5，如正例前 3 次全触发可停）。
3. **通过阈值（§6.3.4）**：每条应触发查询触发率 > 0.5；每条不应触发查询触发率 < 0.5。
4. **留痕**：结果记入本目录 `runs.md`（每次运行：查询ID/轮次/是否加载/证据摘要）；汇总后按 §13 C1–C4 核对。

## 四、已知局限（如实记录）

1. **直白锚点占比**：P01/P05/P07 属"查询已直白索要技能所做的事"，按 §6.2.8 任何合格描述都应触发——保留 3 条作基线校准（若连它们都失败说明管线问题而非描述问题），边界样本 5 条承担真正的措辞差距检验。
2. **宿主单一**：全部查询在 WorkBuddy（路径 B）执行；跨宿主触发行为不在本集覆盖范围（对应 V23 待办）。
3. **C4 未含**：泛化终测的 5–10 条全新查询须在 description 定稿后另行构造，措辞不得与本集重叠。
4. **非确定性**：正例触发率即使 >0.5 也存在波动，修订迭代时以冻结切分对比，不跨切分比较。
