# 周报归档库结构与命名规范

## 目录结构

```
weekly-reports/                 # 归档库根目录
├── 2026/
│   ├── W40/                    # ISO 周编号目录
│   │   ├── 张三_周报_2026-10-02.md
│   │   ├── 李四_周报_2026-10-02.docx
│   │   ├── INDEX.md            # 本周索引（姓名/文件/一句话主题）
│   │   └── DIGEST.md           # 本周跨人摘要（可选）
│   └── W41/
└── _template/                  # 团队统一模板（可选，来自 assets/report_template.md）
```

## 规则

1. **周期目录**：ISO 8601 周编号（`datetime.date.isocalendar()`），零填充两位，如 `W07`。
2. **文件命名**：`{姓名}_周报_{周期截止日}.{ext}`，截止日为该 ISO 周的周五（`fromisocalendar(y, w, 5)`）。保留原始扩展名。
3. **版本**：同一人同一周期重复归档时，新文件覆盖旧文件，旧文件改名为 `{原名}.bak.{归档当日日期}`。
4. **INDEX.md**：每周目录一份，表格三列：姓名 / 文件名 / 一句话主题。归档动作后必须更新。
5. **DIGEST.md**：按"整体进展 / 风险与阻塞 / 下周重点"三节撰写，只聚合已归档内容，不虚构。
6. **缺失检测**：以 INDEX.md 名单对照团队成员名单（用户提供），缺失者列出提示，不代写。

## 查询

- 某人某周：直接定位 `weekly-reports/{年}/W{周}/{姓名}_周报_*.md`
- 某人全部：`Glob weekly-reports/**/{姓名}_周报_*.md`
- 某周概览：读该周 `INDEX.md`，需要细节再读 `DIGEST.md`
