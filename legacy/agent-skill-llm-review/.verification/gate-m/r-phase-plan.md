## 2. 执行机制

- **每周轻量体检**（自动化）：核对 SKILL.md 行数（V27）、技能目录关键文件哈希漂移（V24）、评审日志 FAIL 计数（V9）；产出一行状态记录。
- **每月汇总**（人工/会话内）：汇总体检记录，统计误报/漏报/脚本失败；输出月度观测摘要并归档 `.verification/run-log.md`（R 阶段产物，detect_stage 的 R 项即检测此文件）。
- **迭代回流规则**：任何运行期修改（V10 沉淀、description/正文/脚本变更）落地后，必须复跑对应门（改 description → 触发门回归；改正文 → 质量门；改脚本 → 冒烟套件）并更新 V29 基线。

## 3. 产物与留痕

- `.verification/run-log.md`：R 阶段观测主台账（每周体检行 + 每月摘要节）。
- 告警即记录：任何阈值命中在 run-log 单独立节，含时间、现象、处置、复跑结果。

## 4. 收口条件

连续 4 周体检全绿（无 V27 预警、无 V24 命中、无误报/脚本失败）且无迭代回流 → 观测降频为每月一次；出现任一 [M] 级命中 → 停用 + 审计 + 人工裁决，不受收口条件约束。
