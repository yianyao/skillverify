# gotchas 候选池（Gate-D 本轮发现）

- archive_reports.py 每轮重跑会重建（覆盖）INDEX.md，多次补档后索引只剩最后一轮内容，须人工重建——建议脚本改为追加合并。
- 脚本作者推断只认"{姓名}_周报"类文件名模式，不做正文署名推断，导致正文有署名的不规范文件也进待确认清单。
- 脚本归档保留源文件扩展名（.txt），与规范命名 {姓名}_周报_{日期}.md 不一致，需人工二次规范化。
- 脚本只复制原文不做模板规范化，"规范化与落盘"（步骤 3）实际靠人工完成，脚本与工作流职责有缝隙。

处置：走 R-02 增长性判定后再决定是否入规范/修脚本。
