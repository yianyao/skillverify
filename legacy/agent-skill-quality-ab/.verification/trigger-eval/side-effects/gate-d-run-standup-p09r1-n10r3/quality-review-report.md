## 四、修复建议（可操作）

1. **H1**：将 frontmatter `version` 改为 `1.2.0` 与更新日志对齐；补齐或删除 1.1.0 空档。
2. **H2**：在技能包内实际提交 `scripts/make_digest.py`，或在文档中写明获取方式与脚本不存在时的降级流程。
3. **H3**：删除 `--no-verify` 与"直接推送到远端 main"表述，改为"提交到特性分支，经 review 后合并；如确需跳过钩子必须显式说明理由并经人工确认"。
4. **H4**：将 `git add -A` 改为"`git status`/`git diff` 确认变更清单后，仅 add 预期文件"。
5. **H5**：description 补写触发场景，例如"当用户要求整理每日站会发言、从日志生成立会摘要时使用"。
6. **H6**：验收标准改为可判定条目，如"提交信息遵循 conventional commits 格式"、"digest.md 覆盖目录内全部 `*.log` 文件且每条摘要含原文出处"。
7. **E1–E5**：删除或落实飞书抓取宣称；补错误处理分支；明确 24 小时的时区与时间基准；摘要按日期命名（如 `digest-YYYY-MM-DD.md`）；`python` 调用注明环境要求并充实"注意事项"。
