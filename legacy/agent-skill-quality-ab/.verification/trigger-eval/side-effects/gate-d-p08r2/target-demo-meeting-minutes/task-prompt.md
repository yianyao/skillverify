# 靶子任务（两臂完全同题，执行前冻结）

## 统一 prompt（原样发给两臂）

请生成一份《Q4 产品规划例会纪要》Word 文档（.docx），要求：
1. 包含会议四要素：会议主题、会议时间、会议地点、参会人（至少 4 人，含主持人）；
2. 包含 3 项会议决议，编号清晰；
3. 包含 2 项待办事项，每项须有负责人和截止日期；
4. 排版须使用真正的标题层级样式（非纯加粗文本），正文中文使用规范中文字体，不得出现乱码；
5. 文档有结构化收尾要素（落款日期、页眉/页脚任一即可）；
6. 完成后校验文件可正常打开，并给出交付说明（文件路径 + 内容摘要）。

## 植入的任务歧义（不告诉两臂子代理，用于探测项 8）

任务未指定具体会议日期与参会人姓名——观察两臂是否主动给出合理默认值并明确标注假设，而非留空或虚构不加说明。

## 断言清单（10 条，text 唯一，冻结于执行前）

1. 产出为合法 .docx 文件且可被 python-docx 正常打开解析
2. 文档包含会议主题、时间、地点、参会人四要素且参会人不少于 4 人（含主持人）
3. 包含 3 项会议决议且编号清晰可辨
4. 包含 2 项待办事项且每项均含负责人与截止日期
5. 标题使用 Word Heading 样式层级（style 名为 Heading/标题类），而非仅加粗的普通段落
6. 正文中文设置了规范中文字体（宋体/微软雅黑等），无乱码字符
7. 文档含结构化收尾要素（落款日期或页眉页脚）
8. 【清单外探测项】对任务未指定的信息（如会议日期、参会人姓名）主动给出合理默认并明确标注为假设/示例
9. 【清单外探测项】生成后执行了文件完整性校验（重新打开/解析验证）并在交付说明中体现
10. 交付说明包含明确的文件路径与内容摘要
