# 清洗说明（Arm-B，未加载技能）

## 输入与产出
- 输入：`data/sales_data_raw.csv`（19 行：18 条订单行 + 1 条"总计"行）
- 产出：`outputs/cleaned_without_skill.csv`（15 行唯一订单，UTF-8-SIG，金额/数量为数值型文本）

## 处理内容与理由
1. **剔除总计行**：末尾"总计"行不是订单数据，且其数值 20529.00 与明细实际合计 18729.00 不符，直接剔除。
2. **去重**：完全重复行 3 条（0124/0128/0134），18 → 15 行。
3. **日期统一为 YYYY-MM-DD**：源数据混有 4 种格式（ISO、`2026/03/10`、`05/03/2026` 型、`March 8, 2026`）。斜杠型日期存在日/月歧义，结合数据整体落在 2026-03~04 的背景，按"日/月"优先解析（05/03/2026 → 2026-03-05，12/03/2026 → 2026-03-12），此假设已在脚本注释中声明。
4. **金额清洗为纯数值**：去除 `¥`、千分位逗号与空格；括号负数 `(2,200.00)` 转为 -2200.00（视为退货/冲销）；统一两位小数。
5. **缺失值 3 处，分别处理**：
   - 00127 数量缺失：按 金额/单价 推断为 3，并标记为推断值；
   - 00129 地区缺失：无可靠依据，填"未知"；
   - 0130 客户名称缺失：填"未知"。
6. **地区归一**：去除首尾空格，英文/大小写变体映射为中文标准名（beijing→北京，SHANGHAI→上海，guangzhou→广州，shenzhen→深圳）。
7. **订单编号统一**：去除前导撇号，统一补齐为 5 位（前导零保留，如 `0124` → `00124`）。
8. **逻辑校验**：核对 数量×单价 与 金额：
   - 00131：3×450=1350 ≠ 500，保留原值并标记待人工核对；
   - 00133：金额为 -2200（退货），与 1×2200 符号相反，属预期业务情形，非数据错误。

## 对账
- 行数：19（原始）→ 18（去总计行）→ 15（去重后）
- 金额合计：明细合计 18729.00，与"总计"行 20529.00 不符（差异 1800.00，总计行本身不可信）
