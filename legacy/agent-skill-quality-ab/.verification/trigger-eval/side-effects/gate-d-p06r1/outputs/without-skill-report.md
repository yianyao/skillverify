# 评审报告：report-formatter 技能（Arm-B / 无技能状态）

对 demo-skill/SKILL.md 的独立评审，结论如下。

## 发现的问题

### 1. 引用的脚本不存在
SKILL.md 要求运行 `python scripts/fmt.py --in report.md --out report.docx`，但技能目录中只有 SKILL.md 一个文件，scripts/fmt.py 并不存在。用户安装该技能后第一步就会失败。

修复建议：补充 scripts/fmt.py 实现，或在文档中说明脚本需要单独下载。

### 2. 备份路径硬编码
文档要求备份放到 `C:\Users\admin\templates\backup\` 下。这是他人机器上的用户目录，换台电脑必然失败，而且把备份写进 templates 目录也不合理。

修复建议：改为相对路径或从环境变量读取。

### 3. 备份要求自相矛盾
"注意事项"里第一条说"始终先备份原文件再转换"，第二条紧接着说"无需备份，直接覆盖输出文件即可"。两条指令冲突，执行者无所适从。

修复建议：删掉第二条，或明确说明备份仅针对特定场景。

### 4. 版本号对不上
frontmatter 写 `version: 2.0.0`，但变更日志里最新的条目只有 v1.3。要么是漏写日志，要么是版本号写错。

修复建议：补充 v2.0.0 的变更日志条目。

### 5. 描述与内容不完全匹配
description 声称"支持模板、样式与批量处理"，但正文没有讲模板和样式怎么配置，批量模式只在变更日志里出现过一次。

修复建议：补充模板/样式的配置章节，或收敛 description 的承诺范围。

## 总结
该技能的核心思路（markdown 转 docx）是合理的，但当前状态不可用：核心脚本缺失是阻断性问题，另有路径硬编码和指令冲突两处需要修复。
